## Original Feedback
> CleanUps mit Teams verbinden? Manche Teams organisieren regelmässig Cleanups. Bisher sind CleanUps in CleanCentive immer von Personen organisiert. Wie können wir deutlich machen, dass der CleanUp von einem Team organisiert wird?

## Analysis
There is no relation between `cleanups` and `teams` anywhere in the schema; organizer-ship is modelled only
per person via `cleanup_participants.role = 'organizer'` (`backend/src/cleanup/cleanup-participant.entity.ts`).
The concrete case is the team "Summit Foundation - Clean-up Tour" (`019dee5e-d105-73f8-a3a1-eb077bed9bb1`),
whose seven hand-entered cleanups are indistinguishable from any individual's on `/cleanups`, and whose team
page (`frontend/src/components/TeamDetail.tsx`) has no place to show them.

Two things are missing: a data link (nullable `cleanups.team_id`) and the surfaces that make it visible —
a "Cleanups" section on the team page, an "Organized by <Team>" mark on the cleanup card and header, and a
way for team organizers to set the link when creating or editing a cleanup. The same link is what the
Cleanup Feeds feature (automatic mirroring of external listings into a team) writes, so team organizers must
also be able to edit team-linked cleanups they did not create (`CleanupService.ensureOrganizer` is currently
participant-only).

## Implementation Plan
1. Backend: nullable `cleanups.team_id` + migration; `team: {id, name} | null` on cleanup payloads (hidden for
   unlisted teams to non-members); `team_id` filter on `GET /cleanups/search`; `teamId` on
   `POST /cleanups` / `PUT /cleanups/:id` validated against `team_memberships.role = 'organizer'`;
   team organizers count as cleanup organizers (`canManage` in detail payload).
2. Frontend: extract `cleanup/CleanupCard.tsx`; "Cleanups" section on `TeamDetail` (upcoming first, then
   past, via `lib/teamCleanups.ts`); team badge on the list card; "Organized by <Team>" link in
   `CleanupHeaderCard`; optional "Organized by team" select on create and edit, listing the user's
   organizer teams.
3. i18n en/de/fr (`cleanups.json`, `teams.json`); Playwright `e2e/teams-organized-cleanups.spec.ts`.

Full plan: `~/.claude/plans/the-summit-foundation-team-luminous-donut.md` (also covers the Cleanup Feeds
feature that builds on this link).
